Time (Rome) Session
14:00 to 16:00 Part I: Basics and optimization
Introduction and RL primer What agentic search is and how it differs from traditional human-driven search and from standard single-step retrieval-augmented generation (RAG), followed by a short primer on the post-training and RL concepts used later, such as policies, reward design, and on-policy versus off-policy training.
Optimization paradigms Methods organised by what is optimized: neither the agent nor the search component, the agent only, the search component only, or both jointly.
  • No optimization (prompting only): prompting agents to formulate queries, search iteratively, and use the retrieved evidence (e.g., ReAct, IRCoT, Search-o1)
  • Agent learns to search: training agents to use a fixed search component, from supervised fine-tuning to on-policy RL (e.g., Search-R1) and off-policy RL (e.g., KARL)
  • Search learns to serve agents: training retrievers that read the agent's reasoning or learn from agent-oriented supervision (e.g., AgentIR, LRAT, Critic-R)
  • Agent–search joint optimization: training agents and search models so that each adapts to the other (e.g., Agentic-R, CoSearch)
Live demonstration and hands-on A Colab notebook on BrowseComp-Plus, an open-source benchmark for agentic search over a fixed web document collection. We run an agent on one complex question, analyse its trajectory of reasoning and search calls step by step, swap in different agent backbones and retrievers, and compare agent harnesses. Participants can watch or run the notebook themselves; we host the agent models and retrievers, so no GPU is needed.
Tea break · 16:00 to 16:30
16:30 to 18:30 Part II: Long-horizons, evaluation and beyond
Long-horizon agentic search (deep research) Extending agentic search from a few rounds of search and reasoning to open web research workflows in which an agent decomposes complex questions, gathers and verifies evidence across many sources, and synthesizes a grounded answer or report.
  • Two basic paradigms: reasoning-intensive question answering and long-form report generation
  • Context management: keeping a compact working state through compression, memory updates, or branching and folding the context
  • Efficiency: reaching answers with fewer but more targeted search and reasoning steps
Evaluation for agentic search From recall of the search results and answer matching of short answers to the evaluation of long-form reports, which have no single correct answer.
  • Criteria-based evaluation: an LLM judge scores a report against a reference report on task-specific criteria
  • Nugget-based evaluation: checking whether a report correctly answers the questions that represent the required information, with supporting citations
  • Citation-based evaluation: checking whether each citation supports its claim and whether any factual claim lacks a citation, illustrated with TREC RAGTIME
Beyond text, a single language and the web
  • Multimodal: agents that search over images and long-form videos
  • Cross-lingual: agents whose supporting evidence is in languages other than that of the question
  • Domain-specific: agents that use domain-specific tools in legal, medical and enterprise settings
Conclusion and open challenges Key takeaways, open challenges and future directions for agentic search, and an open discussion with the audience.
